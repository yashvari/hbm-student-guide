1. Convert 3.5 mm/ms into m/s. Explain why they have the same numeric value.
2. Regenerate the force figure. Identify which trace comes from this run and which traces are published reference data.
3. Read `analysis/force_metrics.csv`. Calculate the percentage difference between 3.913 and 4.601 kN. Explain why that alone is not a validation score.
4. Compare raw and filtered acceleration. State the filter class, processing order and why filtering the resultant directly gives a different operation.
5. Write a one-page report: question, model, numerical checks, response comparison, limitation and next controlled test.

Expected checks: 3.5 m/s; about 14.95% lower peak; X/Y/Z filtered before forming the resultant. Energy checks and force comparison answer different questions.
